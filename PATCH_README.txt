VELMORA MANAGER V65 — HOMEPAGE PRIORITY UX / CLUB PULSE

What this patch does
- Needs Your Attention cards now use semantic category colour, iconography and a restrained full-card tint.
- Deadline urgency is a separate visual layer with TODAY, days-left and urgency treatments.
- Existing task navigation and track, remind and dismiss controls are preserved.
- Club Pulse is now a compact executive view of supporter mood, dressing-room atmosphere and board confidence.
- Pulse states and trends are calculated from live career results, player happiness, captain influence and board-confidence data.
- Long season context is constrained to one line and the panel no longer scrolls or clips its first-frame status.
- Root and dist production files are kept in sync by the normal build.

Install
Extract this folder into the main Velmora Manager folder and overwrite matching files. Keep your existing assets/data folders; no new art assets are required.
